# Student Academic Performance Analysis and Early Risk Prediction Using Data Science

A comprehensive data science project designed to analyze student academic performance metrics, uncover hidden behavioral and educational trends, and deploy predictive machine learning models for early risk detection and targeted academic intervention.

## 🚀 About the Project
This repository contains data science pipelines, Exploratory Data Analysis (EDA), and machine learning models aimed at identifying students who may be at academic risk early in their educational journey, allowing institutions to provide timely support.

## 📁 Project Structure
- `student-academic-risk-prediction-github.zip`: Contains the core project archives, datasets, scripts, and model notebooks.

## 🛠️ Tech Stack & Libraries
- **Language:** Python
- **Data Analysis & Manipulation:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-Learn

## 📊 Features
- Data preprocessing and cleaning of student performance metrics.
- Exploratory data analysis (EDA) to visualize key performance trends.
- Predictive modeling for early identification of at-risk students.
